# Simple word list

This list is not the ASD-STE100 dictionary. It is a short list of frequent complex words and phrases, with a simple replacement. `scripts/ste_check.py` reads the table below. To add a pair, add a row. The left column is case-insensitive, and it can contain more than one word.

A replacement can need a change to the sentence. Example: "ensure that X" → "make sure that X".
